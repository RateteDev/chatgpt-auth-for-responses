# 画像生成

`imagegen` はプロンプトから画像を保存するCLIです。参照画像がある場合は `--reference <画像パス>` を付けます。複数の参照画像は繰り返し指定します。最新の引数は `imagegen --help` で確認してください。

CLIがない環境では `bun add -g github:RateteDev/chatgpt-auth-for-responses` でインストールします。認証には Codex CLI のログインで作られる `~/.codex/auth.json` を使います。

出力は保存パスです。プロジェクトの成果物として使うなら、適切な場所へ配置して参照元も更新してください。試作画像の保存先は、ユーザーが削除を指示するまで残します。

被写体、構図、光、色調、スタイルを具体的に伝えます。参照画像があるときは何を残して何を変えるかもプロンプトに書きます。別々の意図で作る画像はプロンプトを分けて呼び出してください。

このエンドポイントは非公開です。断続的に404になる場合は、時間をおいて再試行してください。
